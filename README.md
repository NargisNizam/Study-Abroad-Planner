
# 🌍 Study Abroad Planner

A web-based Study Abroad Planner that helps students explore study-abroad planning through a simple and user-friendly interface.

## ✨ Features

- Study abroad planning interface
- FastAPI backend
- Interactive frontend
- Demo planning mode
- Budget allocation example
- Responsive web design

## 🛠️ Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Jinja2

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/NargisNizam/Study-Abroad-Planner.git
```

2. Open the project folder:

```bash
cd Study-Abroad-Planner
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate it on Windows:

```powershell
.\venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install fastapi uvicorn jinja2 python-multipart python-dotenv openai-agents
```

6. Run the application:

```bash
uvicorn main:app --reload
```

7. Open in your browser:

```text
http://127.0.0.1:8000
```
